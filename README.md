# brilliantwear-pmsg

## BLEPS demo ([basic](https://brilliantsole.github.io/brilliantwear-pmsg/index.html), [polished](https://brilliantsole.github.io/brilliantwear-pmsg/default.html))
- [index.html](https://github.com/brilliantsole/brilliantwear-pmsg/blob/main/index.html) is a basic page showcasing brilliantwear's ability to connect/record data.
- [index-minimal.html](https://github.com/brilliantsole/brilliantwear-pmsg/blob/main/index-minimal.html) is a single file containing [index.html](https://github.com/brilliantsole/brilliantwear-pmsg/blob/main/index.html)'s javascript inside, to be used to drop into any AI tool for reference
- [index-ui.html](https://github.com/brilliantsole/brilliantwear-pmsg/blob/main/index-ui.html) is an example of a nicer front-end (generated by dragging [index-minimal.html](https://github.com/brilliantsole/brilliantwear-pmsg/blob/main/index-minimal.html) into an AI tool and simply asking it to "create a nicer UI"
