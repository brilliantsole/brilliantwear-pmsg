# brilliantwear-pmsg

## BLEPS demo ([basic](https://brilliantsole.github.io/brilliantwear-pmsg/index.html), [polished](https://brilliantsole.github.io/brilliantwear-pmsg/default.html) versions)
- [index.html](https://github.com/brilliantsole/brilliantwear-pmsg/blob/main/index.html) is a basic page showcasing brilliantwear's ability to connect/record data.
- [default.html](https://github.com/brilliantsole/brilliantwear-pmsg/blob/main/default.html) is an example of a nicer front-end
- [index-minimal.html](https://github.com/brilliantsole/brilliantwear-pmsg/blob/main/index-minimal.html) is a single file containing [index.html](https://github.com/brilliantsole/brilliantwear-pmsg/blob/main/index.html)'s javascript inside, to be used to drop into any AI tool for reference

- [imu.html](https://github.com/brilliantsole/brilliantwear-pmsg/blob/main/index.html) is a basic page showcasing brilliantwear's ability to connect/record data.
